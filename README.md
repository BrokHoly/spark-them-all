# Spark Them All
A little game for school (MAR)

**@authors** :
- [Abdelali Ichou](https://github.com/abdelaliichou)
- ...
- Baptiste Bricard


Here are all the respected constaints : 
- Contrôle du joueur : le joueur peut se déplacer et effectuer différentes actions.
- Ennemis “AI” : le jeu contient des ennemis qui peuvent avoir un comportement simple, par exemple suivre le joueur, ou plus complexe.




And the missing ones : 
- Environnement et assets 3D: les différents éléments du jeu sont des modèles 3D.
Ceux-ci sont disposés dans un ou plusieurs niveaux afin de constituer
l'environnement du joueur.
- Environnement physique : Le jeu contient différents éléments utilisant le moteur
physique. Par exemple des projectiles.
- Interaction avec l'environnement : l’environnement du jeu contient différents éléments
avec lesquels le joueur peut interagir. Par exemple des leviers ou des objets
destructibles.
- Caméra 3D : le jeu contient une caméra qui suit le joueur.
- Boucle de jeu : le jeu contient un menu de départ, au moins un niveau dans lequel le
joueur peut gagner ou perdre, un écran de fin selon la victoire ou défaite du joueur, la
possibilité de relancer une partie et de quitter le jeu.
- Interface : le jeu contient des menus avec lesquels le joueur peut interagir ainsi que
des éléments d’interface permettant au joueur de suivre son état et/ou son avancé
dans le jeu.
